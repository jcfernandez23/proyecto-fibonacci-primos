# proyecto-fibonacci-primos
# Matemáticas Aplicadas: Fibonacci, Números Primos y Códigos Seguros

Proyecto web interactivo desarrollado con **HTML5**, **CSS3** y **JavaScript Vanilla**.  
La aplicación presenta tres simuladores matemáticos con enfoque académico y visual moderno:

- Análisis de días primos para control y revisión.
- Plan de expansión progresiva con la serie de Fibonacci.
- Generación de códigos seguros y robustos a partir de Fibonacci y números primos.

## Vista general

Este sitio fue diseñado como una plataforma académica con estilo profesional, responsivo y limpio.  
Incluye:

- Encabezado moderno con navegación adaptable.
- Secciones informativas con contexto, objetivos y resumen.
- Tres simuladores separados visualmente.
- Formularios interactivos con validación.
- Resultados dinámicos en pantalla.
- Enlaces al repositorio y a la página publicada.

## Funcionalidades

### 1. Calendario de inspección con números primos
Permite ingresar un rango de días y muestra cuáles son números primos dentro de ese intervalo.

### 2. Plan de expansión con Fibonacci
Genera una secuencia de Fibonacci y calcula una estimación de crecimiento según los datos ingresados.

### 3. Generación de códigos seguros
Produce códigos alfanuméricos más robustos usando una combinación de Fibonacci, números primos y una semilla numérica.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
